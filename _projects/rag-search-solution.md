하이브리드 검색과 LLM을 결합한 RAG 기반 AI 검색 솔루션 VAIV SearchGPT를 개발·운영했습니다.

## 성과

- KorQuAD 1.0 기준 **Recall@5 성능을 80.43%에서 96.34%로 향상**
- 10여 개 공공기관 포함 **누적 60개 이상 서비스 납품** 및 PoC 수행

## 역할

- 키워드 검색, 의미 기반 검색, 재정렬 알고리즘을 적용한 하이브리드 검색 솔루션 VAIV SearchGPT 개발
- 컨테이너 기반 MSA 구조의 RAG 검색 솔루션 아키텍처 설계
- 멀티 어댑터 구조 도입으로 추론 성능 향상 및 GPU 자원 사용 최적화
- VAIVSearch MCP 개발과 사용자 질의 의도 분석 및 다중 도메인·파라미터 최적화가 가능한 LangChain 기반 검색 에이전트 설계 및 구현
